# Tig Short の字幕
{: .no_toc }

Short は動画が1本のため、字幕の設定はすべて**「詳細設定」タブ**にまとまっています。

字幕の共通仕様（対応言語・自動生成の注意・表示CSSなど）は[字幕（CMS共通）]({{ '/cms/subtitle.html' | relative_url }})を参照してください。ここでは Short 固有の操作を説明します。

## 設定場所

コンテンツ詳細 ＞ **詳細設定**タブ

このタブは字幕専用です。ご契約のグループで字幕機能が有効な場合にだけ表示されます。

## 詳細設定タブの構成

| 項目 | 内容 |
|------|------|
| 字幕 デフォルト表示 | 表示する / 表示しない |
| 字幕 公開設定 | 公開 / 内部プレビューのみ限定公開 |
| 字幕 | 自動生成と、言語ごとの字幕ファイルの登録・変更・削除 |
| 字幕表示CSS | 字幕の見た目（文字色・その他CSS） |

設定は、タブ下部の**更新**ボタンで保存します。

### 字幕 デフォルト表示

視聴者が動画を開いたときに、字幕を最初から表示するかどうかを選びます。「表示しない」にした場合でも、視聴者は字幕ボタンから表示に切り替えられます。

### 字幕 公開設定

| 選択肢 | 動作 |
|--------|------|
| 公開 | すべての視聴者に字幕ボタンと字幕が表示されます |
| 内部プレビューのみ限定公開 | 内部プレビューでのみ表示されます。**公開URLでは字幕ボタン自体が表示されません** |

### 字幕

| 操作 | 内容 |
|------|------|
| 自動生成 | 動画の音声から字幕を自動生成します |
| ダウンロード | 登録済みの字幕ファイル（VTT）を取得します |
| 変更 | その言語の字幕を別のファイルに差し替えます |
| クリア | 選択したファイルを取り消します（差し替えをやめる） |
| 削除 | その言語の字幕を削除します |
| ＋ 字幕ファイルをアップロードして追加 | 言語を選んで新しい字幕を追加します |

- 自動生成で作られた字幕は、言語名の後ろに「**(自動生成)**」と表示されます。
- 追加・変更・削除は、**更新**ボタンを押すまで保存されません。
- **自動生成の実行中は、「変更」「削除」「アップロードして追加」が表示されません。**

### 字幕表示CSS

字幕の見た目を設定します。「文字色」と「その他CSS（縁取り・行間・表示位置 等／色は上の専用欄）」の2欄に分かれ、「デフォルトに戻す」で初期値へ戻せます。文字サイズは端末に合わせて自動調整されるため設定できません。

詳しくは[字幕（CMS共通）の「字幕表示CSS」]({{ '/cms/subtitle.html#subtitle-css' | relative_url }})を参照してください。

## 自動生成

「自動生成」を押すとモーダルが開きます。

| 項目 | 内容 |
|------|------|
| 対象言語 | 音声の言語を選びます |
| 英語翻訳字幕も同時に生成する | チェックすると英語の字幕も同時に作成します |

モーダルには次の注意が表示されます。

- 動画から字幕を自動生成します。
- **処理には時間がかかり、処理中は手動での字幕追加、変更、削除などは行えません。**
- **既存の字幕は上書きされます。**
- 音声が入っていない場合やBGMが大きい場合は字幕がうまく作れません。生成後に確認をお願いします。

実行するとボタンが「**自動生成中**」に変わります。生成に失敗した場合は「〇〇 に実行した自動生成処理が失敗しました。」というメッセージが表示され、×で閉じられます。

生成の完了は画面に自動反映されません。**画面を再読み込み**して確認してください。

## 視聴者側の見え方

| 項目 | 内容 |
|------|------|
| 字幕ボタン | 下部コントローラーの**右側（CCアイコン）**。字幕が登録され、かつ公開設定を満たすときだけ表示されます |
| 言語の切り替え | 字幕ボタンを押すとメニューが開き、「オフ」と登録済みの言語から選べます |
| 表示位置 | **下部・中央**（字幕表示CSSで変更できます） |
| 文字サイズ | PC 20px / スマートフォン 15px（自動） |

「字幕 デフォルト表示」が「表示する」の場合、開いた時点で字幕が表示されます。表示する言語は、視聴者のブラウザの言語設定に近いものが自動的に選ばれます。

## ご利用上の注意

- 字幕を視聴者に見せるには、**公開設定を「公開」**にする必要があります。限定公開のままだと、公開URLでは字幕ボタンごと表示されません。
- 自動生成をもう一度実行すると、手で修正した字幕も上書きされます。
