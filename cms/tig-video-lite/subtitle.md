# Tig Video Lite の字幕
{: .no_toc }

Video Lite は複数の動画で構成されるため、字幕の設定は**コンテンツ全体**と**動画1本ごと**の2か所に分かれています。

字幕の共通仕様（対応言語・自動生成の注意・表示CSSなど）は[字幕（CMS共通）]({{ '/cms/subtitle.html' | relative_url }})を参照してください。ここでは Video Lite 固有の操作を説明します。

## 設定場所

| やりたいこと | 場所 |
|-------------|------|
| 表示・公開・見た目をまとめて設定する | コンテンツ詳細 ＞ **オプション** ＞ **字幕** |
| 全動画の字幕をまとめて自動生成する | コンテンツ詳細 ＞ **オプション** ＞ **字幕** |
| 言語ごとに全動画の字幕をダウンロードする | コンテンツ詳細 ＞ **オプション** ＞ **字幕** |
| 動画1本ごとに字幕を登録・変更・削除する | 各動画の編集ポップアップ ＞ **オプション** |

**字幕ファイルの追加・変更・削除は、動画1本ごとの画面でのみ行えます。** 全体の画面からはアップロードできません。

「字幕」タブは、ご契約のグループで字幕機能が有効な場合にだけ表示されます。

## 全体の設定（オプション ＞ 字幕）

「字幕」タブは3つのカードで構成されています。

### 字幕設定

| 項目 | 内容 |
|------|------|
| プレイヤーのデフォルト表示 | 表示する / 表示しない |
| 字幕の公開設定 | 公開 / 内部プレビューのみ限定公開 |

変更しただけでは保存されません。画面右上の**保存**ボタンで保存します。未保存の変更があるときは、その旨が画面上に表示されます。

Video Lite のプレーヤーには字幕の ON/OFF ボタンがありません。そのため、**「プレイヤーのデフォルト表示」の設定に関わらず、字幕が登録されていれば常に表示されます**。字幕を見せたくない場合は、公開設定を「内部プレビューのみ限定公開」にしてください。

### 字幕

コンテンツ全体に対する操作をまとめたカードです。

| 操作 | 内容 |
|------|------|
| 自動生成（全動画一括） | コンテンツ内の**すべての子動画**の字幕を、まとめて自動生成します |
| ダウンロード | 言語ごとに、**全動画分の字幕を1つの ZIP ファイル**にまとめてダウンロードします |

- ダウンロードは、その言語の字幕が1つ以上登録されている場合にだけ表示されます。何も登録されていないときは「字幕未登録」と表示されます。
- ZIP に含まれる各ファイルは、言語・動画・生成日時がわかる名前で出力されます。
- **自動生成の実行中は、一覧ごと非表示になりダウンロードできません。** 完了後に画面を再読み込みしてください。

#### 全動画一括の自動生成

「自動生成（全動画一括）」を押すとモーダルが開きます。

| 項目 | 内容 |
|------|------|
| 対象言語 | 音声の言語を選びます |
| 英語翻訳字幕も同時に生成する | チェックすると英語の字幕も同時に作成します |

モーダルには次の注意が表示されます。

- 全ての子動画に対して字幕の自動生成を開始します。
- **動画がアップロードされていない動画はスキップされます。**
- **既存の字幕は上書きされます。**
- 音声が入っていない場合やBGMが大きい場合は字幕がうまく作れません。生成後に確認をお願いします。

字幕設定に未保存の変更があるときは、**自動的に保存してからモーダルが開きます**（保存に失敗した場合はモーダルが開きません）。

実行中はボタンが「自動生成中」に変わり、押せなくなります。

### 字幕表示CSS

字幕の見た目を**全動画共通**で設定します。「文字色」と「その他CSS（縁取り・行間・表示位置 等）」の2欄に分かれ、「デフォルトに戻す」で初期値へ戻せます。

文字サイズは端末に合わせて自動調整されるため設定できません。詳しくは[字幕（CMS共通）の「字幕表示CSS」]({{ '/cms/subtitle.html#subtitle-css' | relative_url }})を参照してください。

保存は、字幕設定と同じく画面右上の**保存**ボタンで行います。

## 動画1本ごとの設定（オプションタブ）

動画の編集ポップアップを開き、**オプション**タブに切り替えます。

- ポップアップは「**動画管理**」と「**オプション**」の2タブ構成です。
- **ガイド形式・フォーム入力形式のどちらでも同じ操作**ができます。
- **オプションタブは、すでに登録済みの動画を編集するときにだけ表示されます。** 新規登録中の動画には表示されないため、いったん登録してから開いてください。

### 登録済み字幕

登録されている言語が一覧表示され、言語ごとに次の操作ができます。

| 操作 | 内容 |
|------|------|
| ダウンロード | その言語の字幕ファイル（VTT）を取得します |
| ゴミ箱アイコン | その言語の字幕を削除します（確認ダイアログが出ます） |

字幕が1つも無いときは「字幕が登録されていません」と表示されます。

### 字幕をアップロード

1. **言語**を選びます。
2. 「**ファイルを選択**」から VTT ファイルを選びます（選択後はファイル名が表示され、ゴミ箱アイコンで取り消せます）。
3. 「**アップロード**」を押します。

すでに同じ言語の字幕がある場合は、新しいファイルで置き換わります。

### 字幕を自動生成

この動画1本だけを対象に自動生成します。

| 項目 | 内容 |
|------|------|
| 言語 | 音声の言語を選びます |
| 英語も同時に生成する | チェックすると英語の字幕も同時に作成します |

- **動画がアップロードされていない場合**は実行できず、「動画がアップロードされていないため字幕を自動生成できません。」と表示されます。
- 実行すると、**その動画の既存の字幕は全言語まとめて置き換わります**。

### 生成中・エラーの表示

| 状態 | 表示 |
|------|------|
| 生成中 | 「字幕を自動生成中です...」と表示され、登録済み字幕の一覧とアップロード欄が隠れます |
| 失敗 | 「字幕の自動生成でエラーが発生しました」と表示され、「エラークリア」ボタンが出ます |

ポップアップを閉じても生成は続きます。あとで開き直すと最新の状態が表示されます。

## 同時に生成できる数

- **全動画一括の生成中**は、個別の動画で自動生成できません。
- **個別の動画が生成中**のときは、全動画一括の生成ができません。
- 別々の動画を個別に生成する場合は、同時に実行できます。

## 視聴者側の見え方

| 項目 | 内容 |
|------|------|
| 字幕の ON/OFF ボタン | **ありません**（字幕が登録されていれば常に表示されます） |
| 言語の切り替え | プレーヤー上では切り替えられません |
| 表示位置 | **映像エリアの上部・左寄せ**（字幕表示CSSで変更できます） |
| 文字サイズ | PC 20px / スマートフォン 15px（自動） |

表示される言語は、視聴者のブラウザの言語設定 → 英語 → 登録順の先頭、の順で自動的に決まります。動画が切り替わったときも、同じ言語が引き継がれます。切り替え先にその言語が無い場合は、同じ順番で選び直されます。

## ご利用上の注意

- 字幕を視聴者に見せるには、**公開設定を「公開」**にする必要があります。
- 全動画一括の自動生成は、動画の本数によっては完了までに時間がかかります。
- 生成の完了は画面に自動反映されません。**画面を再読み込み**して確認してください。
