# Tig Branch Video の字幕
{: .no_toc }

Branch Video は複数の動画で構成されるため、字幕の設定は**コンテンツ全体**と**動画1本ごと**の2か所に分かれています。

字幕の共通仕様（対応言語・自動生成の注意・表示CSSなど）は[字幕（CMS共通）]({{ '/cms/subtitle.html' | relative_url }})を参照してください。ここでは Branch Video 固有の操作を説明します。

## 設定場所

| やりたいこと | 場所 |
|-------------|------|
| 表示・公開・見た目をまとめて設定する | コンテンツ詳細 ＞ **詳細設定** |
| 全動画の字幕をまとめて自動生成する | コンテンツ詳細 ＞ **詳細設定** |
| 言語ごとに全動画の字幕をダウンロードする | コンテンツ詳細 ＞ **詳細設定** |
| 動画1本ごとに字幕を登録・変更・削除する | [個別動画の詳細]({{ '/cms/tig-branch-video/node-detail.html' | relative_url }}) ＞ **詳細設定** |

**字幕ファイルの追加・変更・削除は、個別動画の画面でのみ行えます。** コンテンツ詳細の画面からはアップロードできません。

字幕の項目は、ご契約のグループで字幕機能が有効な場合にだけ表示されます。

## 全体の設定（コンテンツ詳細 ＞ 詳細設定）

「詳細設定」タブの下部に、字幕の項目が追加されます。自動再生・コントロールバーなど既存の項目はそのままです。

### 字幕 デフォルト表示

視聴者が動画を開いたときに、字幕を最初から表示するかどうかを選びます（表示する / 表示しない）。

### 字幕 公開設定

| 選択肢 | 動作 |
|--------|------|
| 公開 | すべての視聴者に字幕が表示されます |
| 内部プレビューのみ限定公開 | 内部プレビューでのみ字幕が表示されます |

### 字幕

コンテンツ全体に対する操作をまとめた欄です。

| 操作 | 内容 |
|------|------|
| 自動生成 | コンテンツ内の**すべての動画**の字幕を、まとめて自動生成します |
| ダウンロード | 言語ごとに、**全動画分の字幕を1つの ZIP ファイル**にまとめてダウンロードします |

言語の一覧には、字幕が1つ以上登録されている言語だけが並びます。**この画面では「変更」「削除」「アップロードして追加」は表示されません**（個別動画の画面で行います）。

### 字幕表示CSS

字幕の見た目を**全動画共通**で設定します。「文字色」と「その他CSS」の2欄に分かれ、「デフォルトに戻す」で初期値へ戻せます。文字サイズは端末に合わせて自動調整されるため設定できません。

詳しくは[字幕（CMS共通）の「字幕表示CSS」]({{ '/cms/subtitle.html#subtitle-css' | relative_url }})を参照してください。

これらの設定は、タブ下部の**更新**ボタンで保存します。

## 動画1本ごとの設定（個別動画 ＞ 詳細設定）

個別動画の詳細画面で「**詳細設定**」タブを開くと、シークバー・終了時の動作などの下に「字幕」欄があります。

| 操作 | 内容 |
|------|------|
| 自動生成 | この動画1本を対象に字幕を自動生成します |
| ダウンロード | 登録済みの字幕ファイル（VTT）を取得します |
| 変更 | その言語の字幕を別のファイルに差し替えます |
| クリア | 選択したファイルを取り消します（差し替えをやめる） |
| 削除 | その言語の字幕を削除します |
| ＋ 字幕ファイルをアップロードして追加 | 言語を選んで新しい字幕を追加します |

- 自動生成で作られた字幕は、言語名の後ろに「**(自動生成)**」と表示されます。
- 追加・変更・削除の内容は、タブ下部の**更新**ボタンで保存されます。
- **自動生成の実行中は、「変更」「削除」「アップロードして追加」が表示されません。**

## 自動生成

「自動生成」を押すとモーダルが開きます。全体・個別のどちらも同じモーダルです。

| 項目 | 内容 |
|------|------|
| 対象言語 | 音声の言語を選びます |
| 英語翻訳字幕も同時に生成する | チェックすると英語の字幕も同時に作成します |

モーダルには次の注意が表示されます。

- 動画から字幕を自動生成します。
- **処理には時間がかかり、処理中は手動での字幕追加、変更、削除などは行えません。**
- **既存の字幕は上書きされます。**
- 音声が入っていない場合やBGMが大きい場合は字幕がうまく作れません。生成後に確認をお願いします。

実行するとボタンが「**自動生成中**」に変わります。生成に失敗した場合は「〇〇 に実行した自動生成処理が失敗しました。」というメッセージが表示され、×で閉じられます。

### 同時に生成できる数

- **全体の一括生成中**は、個別の動画で自動生成できません。
- **個別の動画が生成中**のときは、全体の一括生成ができません。

この状態で実行すると「他の動画の字幕を生成中のため、実行できません。しばらく待ってから再度お試しください。」と表示されます。

## 視聴者側の見え方

| 項目 | 内容 |
|------|------|
| 字幕の切り替え | プレーヤーの**歯車（設定）** ＞ **字幕** から、言語の選択とオフができます |
| 表示位置 | **下部・中央**（字幕表示CSSで変更できます） |
| 文字サイズ | PC 20px / スマートフォン 15px（自動） |

視聴者が言語を選んでいない場合は、ブラウザの言語設定 → 英語 → 登録順の先頭、の順で自動的に決まります（「字幕 デフォルト表示」が「表示する」の場合）。

**分岐で動画が切り替わったときも、視聴者が選んだ言語が引き継がれます。** 切り替え先の動画にその言語の字幕が無い場合は、同じ順番で別の言語が選ばれます。どれも無い場合は字幕オフになります。

分岐先の動画に字幕が登録されていないと、その動画の間だけ字幕が表示されません。**すべての動画に同じ言語の字幕を用意する**ことをおすすめします。

## ご利用上の注意

- 字幕を視聴者に見せるには、**公開設定を「公開」**にする必要があります。
- 一括生成は動画の本数によっては完了までに時間がかかります。生成の完了は画面に自動反映されないため、**画面を再読み込み**して確認してください。
